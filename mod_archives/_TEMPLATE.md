# B42.22 中文 Mod 手册格式

本手册覆盖日常组合与兼容候选。当前数量和归属见 [INDEX.md](INDEX.md)；运行证据见 [COMPATIBILITY.md](../COMPATIBILITY.md)。生成档案不会切换游戏组合。

## 按什么顺序查

1. **整车**：完整车辆 ID、当前中文名、英文名或脚本名、变体说明。生成车辆菜单使用 `<module>.<vehicle>`，例如 `Base.70dodgeRT`；显示中文时搜索译名。
2. **普通物品与书籍**：可放入背包的物品。手册注明脚本声明解锁的配方。
3. **维修配件**：恢复车辆部件的物品，列出关联车型及安装槽位。
4. **改装配件**：防护件、保险杠、行李架等安装物品。分类依据安装关系；不因英文名相似就承诺效果。
5. **共享配件**：由已启用依赖或游戏原版提供的物品，单列提供者，不重复计入本 Mod 的本地定义数。
6. **制作配方**：制作界面名称、用途、完整配方 ID 和来源。配方 ID 不能用于添加背包物品或生成车辆。
7. **内部定义、历史分支与未解析引用**：车辆模板、零件槽位、内部容量载体、作者标记过时的 item、旧分支及未定位引用；不进入正常刷取建议。
8. **概览与人工证据**：当前端别、版本范围、资源层、历史实测与补丁记录。

每个实际内容行都有中文用途说明和来源。不能确认的具体功能标待核实，不能把“有定义”写成“实刷成功”。`Not in use` 要结合当前模板引用解释，不自动当作停用。

## 名称与来源

- 有效内容来自所选 profile 的原件、`common`、不高于引擎版本的最高有效数字目录，以及相同路径的 Overlay。物品、整车、配方、模板分别解析，不遍历并合并历史版本。
- 来源脚注使用 `A004/workspace/mods_library/` 下的相对路径和行号；`Overlay/<文件夹>/` 指 `A004/workspace/patches/mods/<文件夹>/`，`游戏原版/` 指当前 B42.22 客户端 Game 目录。
- 汉化读取当前启用客户端 Mod 的有效 JSON / TXT 翻译，支持 UTF-8 与 GB18030。完整 ID 不做大小写转换，不用替换字符掩盖解码错误。
- 游戏显示名与中文用途分列。缺中文时依次回退有效英文译文、脚本显示名，并标明缺译；多个有效译文不同时列出冲突和所有来源。profile 的先后顺序本身不足以证明 JSON、TXT 及运行时 Lua 改写最终谁胜出。
- 模板短引用按机修类型后缀匹配到现有完整物品定义时，注明属于静态映射。适配、安装和联机行为仍需游戏验证。

## 人工说明与安全更新

`tools/mod_catalog.json` 保存 `cn / brief / cat / what / mp / note`，以及：

| 字段 | 用途 |
| --- | --- |
| `file` | 固定现有文件名，保持链接 |
| `content` | 以完整 ID 为键保存用途、分类、特殊状态和补充 `sources`；人工解释不冒充译文 |
| `retained` | 从原档案保留的人工排查、风险、补丁及实测记录 |
| `historical` | 明确排除的旧分支内容或旧统计纠正 |

多个子 Mod 仍可共用原有档案页，页内分列端别。目录项数、档案页数、车辆数和物品数分别统计。再次生成不会删除视图外或已移出页面；人工记录以保留区原文存续，旧组合与旧数量只作历史线索。

在仓库目录运行：

```bash
python -B tools/mod_archive.py --profile b422-compat
python -B tools/test_mod_archive.py
```

先预览可用 `--out <临时目录>/mod_archives`；README 会写到其父目录。`--report <临时路径>.json` 输出静态核对数据。`--import-notes` 用于一次性将旧格式人工说明和文件名导入 catalog，不作为日常更新步骤。

## 统计与验证边界

- 内容数量只统计当前有效定义。索引总数按完整 ID 去重，包含覆盖原版的定义，不表示全部是新增车型或新增物品。
- 物品定义数包含当前脚本保留的内部、占位和过时 item。这些条目在内部定义区独立列出，不计作正常背包刷取建议；槽位和模板仍不计入物品定义数。
- 配方产出只是引用；只有定位到有效物品定义后才可进入共享物品表。模板、模型、槽位不算整车或背包物品。
- 文件大小按完整原件目录统计，与有效内容数量分开。
- 当前日常组合的仅客户端项由 profile 动态统计；服务端清单和进服重载行为另查兼容说明。
- 本轮可确认有效源码及 Owner 提供的挑战者截图；没有游戏实刷、安装、联机或存档验收证据，也没有独立 Review verdict。
- Mod 版权归各自作者，本仓库不分发游戏或 Mod 二进制。
